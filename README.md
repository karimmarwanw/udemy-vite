# Udemy Landing Page (React + Vite)

Simple Udemy landing page clone for lab work.

## How to run

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start dev server:

   ```bash
   npm run dev
   ```

3. Open the URL that Vite prints in the terminal (usually http://localhost:5173).

The UI is implemented with React components and plain CSS.
All dummy data is defined in `src/data/dummyData.js`.
